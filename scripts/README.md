# Scripts

このディレクトリ配下のスクリプトは、`infra/main.sh` で構築されるメンテナンス VM から実行することを想定しています。

前提:

- 対象リソース（AKS、Database など）とのプライベート通信が可能な実行環境であること

ディレクトリ構成:

- `scripts/init/`
  - 初期構築時に一度だけ実行するスクリプトを配置します。
  - `maintvm/`
    - メンテナンス VM 自体のセットアップに使うスクリプトを配置します。
- `scripts/ops/`
  - 定常運用で継続的に利用するスクリプトを配置します。

## 初期構築時の実行フロー（ベース）

1. メンテVMの初期設定
2. メンテVMに必要なツールインストール
3. agicコントローラの導入
4. kedaコントローラの導入
5. Docker image の build / ACR push
6. SQL Database のデータベース初期設定（スキーマ、ロールの作成）
7. アプリ部分のhelm展開（`k8s` フォルダの Helm）
